# Staj Çalışmaları

Staj sürecinde hazırladığım haftalık raporlar ve simülasyon çalışmaları. Süreç, temel konulara aşinalık kazandığım hazırlık haftalarıyla başlayıp ana staj haftalarıyla devam ediyor.

| 1. hafta | 7–13 Eylül | Şematik okuma, dijital mantık | [Rapor](Hazirlik_haftalari/01_Hafta_1/Hafta_1_Rapor.docx) |
| 2. hafta | 14–20 Eylül | Pointer, struct, bitwise işlemler, Wokwi ile STM32 | [Rapor](Hazirlik_haftalari/02_Hafta_2/Hafta_2_Rapor.docx) · [LED blink](Hazirlik_haftalari/02_Hafta_2/simulasyon/led_blink.zip) · [Buton ile LED](Hazirlik_haftalari/02_Hafta_2/simulasyon/buton_led.zip) |
